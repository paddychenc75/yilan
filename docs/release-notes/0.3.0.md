## 中文

### 新功能

- **评星**：按 `1` 到 `5` 给照片打星，按 `0` 清除，也可以直接点缩略图栏上方的五颗星。星级记在照片旁边同名的 `.xmp` 小文件里，照片本身不会被改动，支持读取 `.xmp` 的软件能读到。
- **筛选**：按 `⌘F` 或点顶部的漏斗按钮，按星级（N 星及以上、仅 N 星、未评星）和文件格式筛选，可以叠加。
- **基本编辑**：按 `E` 进入编辑，可以裁切（自由或固定比例）、旋转、调整分辨率。默认另存为副本「名字 编辑」，原图不动；也可以选择替换原图，原图会进废纸篓，可按 `⌘Z` 撤销。
- **保存旋转**：浏览时把照片转了方向，可以点「保存旋转」把方向存下来。JPEG、HEIC、TIFF 是无损保存，画质不变。
- **缩放控件**：顶部显示当前缩放比例，点开可以选适应窗口、实际大小和常用比例。
- **更新提醒**：有新版本时启动后会提示，可以查看更新说明、稍后再说或跳过这个版本。可在「设置 › 通用」里关闭自动检查。
- **设为默认打开方式**：在「设置 › 文件格式」里按格式、按分组或一次全部把一览设为默认打开方式，也可以一键交还给系统自带应用。
- **支持 macOS 15**：现在 macOS 15（Sequoia）也能安装使用。

### 改进

- **排序**：文件按不含扩展名的名字排序，同名的 RAW 和 JPEG、原图和编辑后的副本会挨在一起。
- **切换语言**：切换界面语言后会自动重新打开，程序坞里不再多出一个图标。

### 修复

- **双击标题栏没反应**：以前双击窗口顶部空白处不会放大窗口，现在按系统设置放大或最小化。

### 升级须知

- **快捷键有变化**：数字键 `1` 到 `5` 现在用来评星，`0` 清除星级，不再用来缩放。缩放改为：`Z` 在适应窗口和实际大小之间切换，`⌘0` 实际大小，`⌘9` 适应窗口。

## English

### New

- **Star ratings**: press `1` to `5` to rate a photo and `0` to clear, or click the five stars above the thumbnail strip. Ratings are stored in a small `.xmp` file next to the photo, so the photo itself is never changed, and apps that read `.xmp` sidecar files can pick them up.
- **Filter**: press `⌘F` or click the funnel button in the top bar to filter by rating (N stars and up, exactly N stars, unrated) and by file format. Filters can be combined.
- **Basic editing**: press `E` to edit. Crop (free or fixed ratio), rotate and resize. By default the result is saved as a copy named "name edited" and the original is untouched. You can also replace the original, which moves it to the Trash; `⌘Z` undoes that.
- **Save rotation**: after rotating a photo while browsing, click "Save Rotation" to keep the new orientation. For JPEG, HEIC and TIFF this is lossless.
- **Zoom control**: the top bar shows the current zoom level; click it for fit to window, actual size and common zoom levels.
- **Update reminder**: when a new version is out, the app tells you at launch. You can read the release notes, decide later, or skip that version. Automatic checks can be turned off in Settings › General.
- **Set as default app**: in Settings › File Formats, make Yilan the default app per format, per group or for everything at once, or hand everything back to the built-in apps in one click.
- **macOS 15 support**: Yilan now also runs on macOS 15 (Sequoia).

### Improved

- **Sorting**: files are sorted by name without the extension, so a RAW and its JPEG, or an original and its edited copy, stay next to each other.
- **Language switch**: after changing the UI language the app reopens by itself and no longer leaves an extra icon in the Dock.

### Fixed

- **Double-clicking the title bar did nothing**: double-clicking the empty area at the top of the window now zooms or minimises the window, following your system setting.

### Upgrade notes

- **Shortcuts changed**: the number keys `1` to `5` now set a rating and `0` clears it; they no longer zoom. For zooming, use `Z` to toggle between fit to window and actual size, `⌘0` for actual size and `⌘9` for fit to window.

## 安装 / Install

**系统要求**：macOS 15（Sequoia）或更高版本，Apple 芯片和 Intel 芯片都可以。

**首次打开**：这个版本只做了 ad-hoc 签名。第一次打开被拦下后，到「系统设置 › 隐私与安全性」点「仍要打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/Yilan.app`。

**Requirements**: macOS 15 (Sequoia) or later, Apple silicon or Intel.

**First launch**: this build is ad-hoc signed only. After it is blocked once, click "Open Anyway" in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/Yilan.app`.
