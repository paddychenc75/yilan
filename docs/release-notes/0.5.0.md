## 中文

### 新功能

- **图标视图**：按 `G` 或点顶部的切换按钮，缩略图铺满整个窗口，像访达一样上下滚动。双击、回车或空格看大图，再按 `G`、`Esc` 或空格回来。底部滑块或 `⌘+` / `⌘−` 调缩略图大小。
- **多选**：在图标视图里用 `⌘` 点按、`⇧` 点按、`⌘A` 或在空白处拖框选中多张，`⇧` 加方向键扩大选择。选中后可以一起移到废纸篓（会先确认，`⌘Z` 一次全部放回）、拷贝、按数字键一起评星，也可以直接拖到访达或别的应用里。
- **右键菜单**：在大图、底部缩略图和图标视图里点右键，可以在访达中显示、拷贝、旋转、编辑、看信息、移到废纸篓。
- **拷贝文件**：按 `⌘C` 把当前这一张或选中的文件放到剪贴板，可以粘贴到访达、聊天软件和邮件里。
- **复制到 / 移动到文件夹**：右键菜单和「文件」菜单里新增这两项，把选中的照片连同星级小文件放到你指定的文件夹，同名文件不会被覆盖。
- **拉直**：编辑里新增「拉直」，拖动刻度尺在正负 45 度内微调角度，校正歪斜的地平线，露出的空角会自动裁掉。
- **简洁模式**：只想看图的话，在「设置 › 通用」或「显示」菜单里打开简洁模式，评星、编辑、复制和移动到文件夹的入口都会收起来，保留浏览、筛选、信息、删除和拷贝。已有的星级不会丢，关掉就回来。
- **RAW 导出为 JPEG**：在 RAW 上按 `⇧⌘E` 或用右键菜单，在同一个文件夹里存一张全尺寸的 JPEG「名字 导出」，RAW 本身不会被改动，`⌘Z` 可以撤销。
- **更多相机的 RAW**：新认识三星、宾得、哈苏、飞思、适马、徕卡等品牌的 RAW，以及索尼相机的 HEIF 照片（`.HIF`）。
- **系统解不了的 RAW 也能看**：新相机的 RAW 在较旧的 macOS 上系统还不能解码时，一览改为显示相机存在文件里的预览图，并标注「相机预览图」。可以照常翻看、放大、评星、删除和拷贝。

### 改进

- **内存占用更低**：在最新的 macOS 上连续浏览 RAW 时，内存峰值大约是原来的一半。
- **删除失败的提示更清楚**：文件移不进废纸篓时，直接写明原因（例如没有权限），文件留在原处。

### 升级须知

- **RAW 不能直接编辑了**：以前可以对 RAW 裁切后另存，现在 RAW 只看不改。要编辑请先「导出为 JPEG」（`⇧⌘E`），再编辑导出的那一张。
- **新增快捷键**：`G` 切换画廊视图和图标视图，`⌘C` 拷贝文件，`⇧⌘E` 把 RAW 导出为 JPEG。原有快捷键没有变化。

## English

### New

- **Icon view**: press `G` or use the switch in the top bar to fill the window with thumbnails that scroll like Finder. Double-click, Return or Space opens the photo; `G`, `Esc` or Space takes you back. Change the thumbnail size with the slider at the bottom or `⌘+` / `⌘−`.
- **Multiple selection**: in icon view, `⌘`-click, `⇧`-click, `⌘A` or drag a box over empty space to select several items, and use `⇧` with the arrow keys to extend the selection. Then move them to the Trash together (always confirmed; one `⌘Z` puts them all back), copy them, rate them all with a number key, or drag them straight into Finder or another app.
- **Right-click menus**: right-click the photo, a thumbnail in the strip or an item in icon view to show it in Finder, copy, rotate, edit, show info or move it to the Trash.
- **Copy files**: press `⌘C` to put the current file or the selected files on the clipboard, ready to paste into Finder, chat apps and email.
- **Copy to / Move to Folder**: two new items in the right-click menu and the File menu place the selected photos, together with their rating sidecar files, in a folder you choose. Files with the same name are never overwritten.
- **Straighten**: the editor has a new Straighten tool. Drag the ruler to adjust the angle within ±45° and level a tilted horizon; the empty corners are cropped away automatically.
- **Simple Mode**: if you only want to look at pictures, turn on Simple Mode in Settings › General or the View menu. Rating, editing and copy / move to folder are tucked away, while browsing, filtering, info, delete and copy stay. Existing ratings are kept and come back when you turn it off.
- **Export RAW as JPEG**: on a RAW file, press `⇧⌘E` or use the right-click menu to save a full-size JPEG named "name exported" in the same folder. The RAW file itself is never changed, and `⌘Z` undoes the export.
- **RAW from more cameras**: Yilan now recognises RAW files from Samsung, Pentax, Hasselblad, Phase One, Sigma, Leica and more, plus HEIF photos from Sony cameras (`.HIF`).
- **RAW files macOS cannot decode still open**: when an older macOS cannot decode the RAW from a newer camera yet, Yilan shows the preview the camera saved inside the file and labels it "Camera Preview". You can still browse, zoom, rate, delete and copy as usual.

### Improved

- **Lower memory use**: on the latest macOS, peak memory while paging through RAW files is roughly half of what it was.
- **Clearer message when a delete fails**: if a file cannot be moved to the Trash, the reason is shown directly (for example, no permission) and the file stays where it is.

### Upgrade notes

- **RAW files can no longer be edited directly**: you used to be able to crop a RAW and save a copy. RAW files are now view-only. To edit one, use Export as JPEG (`⇧⌘E`) first, then edit the exported copy.
- **New shortcuts**: `G` switches between gallery view and icon view, `⌘C` copies files, and `⇧⌘E` exports a RAW as JPEG. Existing shortcuts are unchanged.

## 安装 / Install

**系统要求**：macOS 15（Sequoia）或更高版本，Apple 芯片和 Intel 芯片都可以。

**首次打开**：这个版本只做了 ad-hoc 签名。第一次打开被拦下后，到「系统设置 › 隐私与安全性」点「仍要打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/Yilan.app`。

**Requirements**: macOS 15 (Sequoia) or later, Apple silicon or Intel.

**First launch**: this build is ad-hoc signed only. After it is blocked once, click "Open Anyway" in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/Yilan.app`.
