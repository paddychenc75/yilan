## 中文

### 改进

- **更新提醒更及时**：以前每 24 小时才自动检查一次新版本，现在每次打开都会检查（两次之间至少隔 1 小时）。一直开着不关时，每 6 小时在后台检查一次，发现新版本只在「⋯」按钮上显示一个小点，不打断你看图。
- **macOS 15 上文件夹名更清楚**：照片很亮时，顶部第二行的文件夹名现在更容易看清。

### 修复

- **保存旋转后缩略图没变**：点「保存旋转」或在编辑里替换原图后，底部缩略图栏里那一张还是旧方向，现在会马上换成新的。
- **保存旋转后画面空白一下**：保存旋转或撤销时，中间的大图会消失一小会儿再出现，现在画面一直在。
- **撤销保存旋转后文件有细微差别**：撤销后画面和原来一样，但文件本身和原来差几个到几千字节。现在按 `⌘Z` 撤销后，文件和保存前完全相同。

## English

### Improved

- **Timelier update reminders**: the app used to check for a new version only once every 24 hours. It now checks every time you open it (at least 1 hour apart). If you leave it open, it checks in the background every 6 hours and only shows a small dot on the "⋯" button when a new version is out, without interrupting you.
- **Clearer folder name on macOS 15**: on very bright photos, the folder name in the second line at the top is now easier to read.

### Fixed

- **Thumbnail not updated after Save Rotation**: after clicking "Save Rotation", or replacing the original in the editor, the thumbnail in the strip kept the old orientation. It now updates right away.
- **Image went blank briefly after Save Rotation**: when saving a rotation or undoing it, the main image disappeared for a moment before coming back. It now stays on screen.
- **File differed slightly after undoing Save Rotation**: after undoing, the picture was the same but the file itself differed from the original by a few bytes to a few kilobytes. Pressing `⌘Z` now restores the file exactly as it was before saving.

## 安装 / Install

**系统要求**：macOS 15（Sequoia）或更高版本，Apple 芯片和 Intel 芯片都可以。

**首次打开**：这个版本只做了 ad-hoc 签名。第一次打开被拦下后，到「系统设置 › 隐私与安全性」点「仍要打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/Yilan.app`。

**Requirements**: macOS 15 (Sequoia) or later, Apple silicon or Intel.

**First launch**: this build is ad-hoc signed only. After it is blocked once, click "Open Anyway" in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/Yilan.app`.
