## 中文

### 改进

- **RAW 的提示文字更准确**：系统解不了、文件里又没有预览图的 RAW，以前提示「文件可能已损坏」，其实文件没坏；现在说明是这个版本的 macOS 无法解码。显示相机预览图时的说明卡不再一律建议「升级 macOS」，并提示要编辑可以先「导出为 JPEG」。

### 修复

- **左右切换时闪出别的图片**：快速按方向键切换时，画面有时会跳一下，闪出一帧别的照片。现在不会再出现；在 5K、6K 这样的大屏幕上往回翻也更跟手。
- **图标视图双击 RAW 时卡一下**：双击尼康 Z8、徕卡 Q2 这类内嵌预览图特别大的 RAW，放大成大图的动画会顿一下。现在和双击 JPG 差不多顺。

## English

### Improved

- **More accurate RAW messages**: a RAW that the system can't decode and that has no preview inside used to be reported as "the file may be damaged", although the file was fine. The message now says this version of macOS can't decode it. The card shown with a camera preview no longer always suggests upgrading macOS, and points out that you can use Export as JPEG before editing.

### Fixed

- **Another photo flashing while switching**: when switching quickly with the arrow keys, the picture sometimes jumped and showed one frame of a different photo. This no longer happens, and going back is smoother on large 5K and 6K displays.
- **Stutter when double-clicking a RAW in icon view**: double-clicking a RAW with a very large embedded preview, such as files from the Nikon Z8 or Leica Q2, made the zoom animation hitch. It is now about as smooth as double-clicking a JPG.

## 安装 / Install

**系统要求**：macOS 15（Sequoia）或更高版本，Apple 芯片和 Intel 芯片都可以。

**首次打开**：这个版本只做了 ad-hoc 签名。第一次打开被拦下后，到「系统设置 › 隐私与安全性」点「仍要打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/Yilan.app`。

**Requirements**: macOS 15 (Sequoia) or later, Apple silicon or Intel.

**First launch**: this build is ad-hoc signed only. After it is blocked once, click "Open Anyway" in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/Yilan.app`.
