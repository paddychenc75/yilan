# 一览 v0.4 需求文档（PRD）：裁切

状态：范围已确认（2026-11-17），细节在 v0.3 发布后、设计开始前再过一遍。

## 一、背景

用户评论：「功能简单了点，没有修图功能，建议加点基本的修图功能，例如放大缩小，裁切」。放大缩小的入口已在 v0.3 改善，本版本做裁切。

v0.1 的 PRD 写明「不做编辑」。本版本对定位做一次有限的调整：只开放裁切、旋转、调整尺寸这三项「几何改动」，调色和滤镜永远不做。

「按格式设置默认打开方式」原计划在本版本做，2026-11-18 负责人决定提前到 v0.3，见 `changes/v0.3/prd.md`。

## 二、目标与不做的事

**目标**

- 用户不离开一览就能完成裁切这类最常见的小改动。
- 任何情况下都不损坏、不意外覆盖用户的原图。

**不做的事**

- 调色、滤镜、曝光对比度等画质调整，RAW 显影。
- 视频剪辑。
- 批量编辑。

## 三、使用场景

小林要把一张截图发给同事，只想保留中间一块。

1. 用一览打开图片，按 C 进入裁切。
2. 拖动裁切框，回车确认。
3. 一览存出一张新图，原图不动。

## 四、功能需求

### 4.1 功能清单

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| E2 | 裁切 | 按 C 或点工具栏按钮进入裁切。拖动四角和四边调整裁切框，框内拖动可移动。回车确认，Esc 取消 | 必须做 |
| E3 | 裁切比例 | 可选：自由、原始比例、1:1、4:3、3:2、16:9，可一键切换横竖。裁切框内显示三分线，旁边显示裁切后的像素尺寸 | 必须做 |
| E4 | 保存旋转 | 现有的旋转只改显示。新增「保存旋转」：把旋转结果存进文件 | 必须做 |
| E5 | 调整尺寸导出 | 输入宽或高（像素）或百分比，保持比例，另存为新文件。只允许缩小，不做放大 | 尽量做 |
| E6 | 拉直 | 裁切时可微调角度（正负 45 度以内）校正歪斜的地平线 | 以后再议 |

### 4.2 保存规则

- **默认另存为副本**。新文件放在同一文件夹，文件名加后缀，例如「IMG_2052 裁切.jpg」。重名时自动加序号。
- 保存后一览自动跳到新文件，底部缩略图里新文件紧跟在原图后面。
- 新文件沿用原图的格式和拍摄信息（时间、相机、位置、星级）。JPEG 用高质量保存。
- **RAW 只能另存**。RAW 无法改写，裁切或调整尺寸后存成 JPEG 或 HEIF，由用户选择，默认 JPEG。
- 可选「替换原图」，需要用户在保存时主动选择。替换时原图先进废纸篓，可以用 ⌘Z 撤销找回。
- 不支持编辑的类型：视频、GIF 动图、SVG。这些文件上裁切按钮置灰，鼠标悬停提示「此类文件不支持裁切」。
- 保存失败（位置不可写、磁盘满）时弹出提示，说明原因，原图不受影响。

### 4.3 裁切界面要点

- 进入裁切后，底部缩略图和左右切换箭头隐藏，方向键不再切图。
- 裁切框外的区域压暗，框内保持原样。
- 裁切状态下仍可缩放查看细节。
- 界面沿用现有的深色和玻璃质感风格。

## 五、验收标准

- [ ] 裁切并确认后，同文件夹出现新文件，原图内容和修改时间都没变。
- [ ] 新文件的像素尺寸与裁切框显示的一致，拍摄时间、相机、位置、星级都保留。
- [ ] 选定 1:1 等固定比例后，怎么拖动都保持该比例。
- [ ] RAW 裁切后存出 JPEG 或 HEIF，RAW 本身不变。
- [ ] 选择「替换原图」后，原图在废纸篓里能找到，⌘Z 能恢复。
- [ ] Esc 退出裁切，不产生任何文件。
- [ ] 视频、GIF、SVG 上裁切按钮置灰并有提示。

## 六、以后再议

拉直（E6）、颜色标签与旗标、RAW 和 JPEG 配对。
