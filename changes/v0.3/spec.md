# 一览 v0.3 功能规格（spec）：评星、筛选、缩放控件、更新提醒

状态：产品已确认（2026-11-17）。依据：`prd.md`（已确认）、`design/index.html` 和 `design/shots/`（已确认，含 2026-11-17 补充的「视频文件上的五星」和「给开发的说明」）。和 `tech-design.md` 同时写，两份互不矛盾。

## 0. 怎么读

- 每条规则一行，编号「<PRD 编号>-<序号>」，例如 `R1-03`。PRD 4.2 快捷键用 `K`，4.3 星级存储用 `S`，4.4 筛选细节用 `F`，4.5 更新提醒的通用规则用 `U`。
- 规则里的界面文字用文案编号引用，例如 T12，完整的中英文见第 15 节「文案表」。设计稿只给了中文；英文是本规格新写的，要负责人或产品看一遍。
- 尺寸单位是点（pt），以设计稿「给开发的说明」为准；本规格只写行为，尺寸不重复抄。
- 带「待定」的规则依赖第 16 节「需要产品决定」，规则里写的是推荐答案，产品改了答案就改规则。
- 名词：
  - **星级**：0 到 5。0 叫「未评星」。
  - **XMP**：Adobe 定的照片附加信息格式，星级记在其中的 `xmp:Rating` 一项。
  - **内嵌**：星级写在图片文件自己的信息区里。
  - **.xmp 小文件（sidecar）**：放在照片旁边、记星级的小文件。
  - **类型切换**：已有的「全部 / 图片 / 视频」。
  - **筛选**：本版新增的星级、格式两种条件，以后还会加别的。
  - **结果列表**：类型切换和筛选同时满足的文件，按文件名自然排序。缩略图栏、序号、方向键都只针对它。
  - **暂留**：当前文件已经不符合条件，但还留在结果列表里，等用户切走才消失（见 F-01）。

## 1. 键盘打星（R1）

| 编号 | 规则 |
| --- | --- |
| R1-01 | 主窗口是键盘焦点、有当前文件、没有打开删除确认框、更新说明表单、导出表单时，按数字键 1–5（主键盘或小键盘，不按 ⌘ ⌃ ⌥ ⇧）：当前文件的星级变成对应数字。依据 R1 |
| R1-02 | 按下后 0.1 秒内，界面上所有显示这个文件星级的地方都变成新值：画面五星胶囊、缩略图角标、信息面板评星行、序号里的星级（如显示）。不等写盘。依据 R1 |
| R1-03 | 按 0：清除当前文件的星级（变成未评星）。当前文件本来就是未评星时，按 0 什么都不发生：不写盘、不进撤销记录、不提示。依据 R1 |
| R1-04 | 按下的数字和当前星级相同：星级不变、不写盘、不进撤销记录；胶囊照常闪现一次（设置开着时），让用户知道按键被收到。依据 R1、R3a |
| R1-05 | 按 1–5 改变星级时：按 R3a-01 闪现胶囊（设置关掉时不闪），不带出左右箭头和缩放控件；没有文字提示。依据 R1、R3a |
| R1-06 | 清除星级（按 0，或点信息行里当前星级那颗）时，顶部提示条显示 T01，约 1.5 秒后淡出；按 0 时胶囊同样闪现。依据 R1、R2、R3a |
| R1-07 | 按住数字键不放，系统的按键重复不算新的按键：只评一次。依据 R1 |
| R1-08 | 信息面板打开、筛选面板打开、全屏、图片放大、视频播放中，数字键都照常给当前文件评星；筛选面板打开时数字键不改变筛选条件；视频播放中评星不暂停视频。依据 R1、R5 |
| R1-09 | 当前文件显示的是错误卡片（文件损坏、视频无法播放、文件已不在）时不能评星：按 1–5 / 0 显示提示 T03，星级不变。待定 PD-09。依据 R1 |
| R1-10 | 当前文件所在位置不可写（只读磁盘、写保护存储卡、没有写权限）时：按 1–5 / 0 显示 T02，星级不变（见 S-14）。依据 R1、4.3 |
| R1-12 | 当前文件是视频（MP4、MOV、M4V）：按 1–5 不评星，提示条显示 T103 约 1.6 秒；按 0 什么都不发生。不写、不进撤销记录、不建小文件、不闪现、不自动下一张。依据 R1（2026-11-18 改定：v0.3 只给图片评星） |
| R1-13 | 当前文件原有的星级是 -1（别的软件的「排除」）：显示为未评星；按 0 不改动文件、不进撤销记录；按 1–5 照常改写成新星级。依据 4.3、调研报告 E4 |
| R1-11 | 连续快速按不同数字（例如 3、4、5）：界面每次立即变化，每一次都进撤销记录；写盘只保证最后一次的值落到文件里，中间值可以跳过。依据 R1、R7 |

## 2. 缩略图栏信息行里的星、按键闪现、信息面板里的星（R2、R3a）

2026-11-17 产品改定（PRD R2、R3a）：照片上不再有鼠标触发的评星控件。可点的五颗星放进缩略图栏信息行；画面上的胶囊只在按 0–5 时闪现。原 R2-01 ~ R2-05 的鼠标显示规则和 PD-01 作废。

| 编号 | 规则 |
| --- | --- |
| R2-01 | 缩略图栏信息行中间有五颗星：星 16、间距 3、整行宽 92，水平居中在缩略图栏里，和文件名同一行。左边是名称 + 尺寸，右边是（时长 ·）大小 · 格式。依据 R2 |
| R2-02 | 未评星：五颗淡空心星（白 34% 描边）；已评星：前 N 颗亮黄（#FFE2A0），其余仍是淡空心。依据 R2 |
| R2-03 | 鼠标进入整行：没亮的星描边提亮到 60%；指到第 N 颗：第 1…N 颗显示预览（亮黄 45% 填充 + 亮黄描边），不论当前星级；移开恢复。依据 R2 |
| R2-04 | 指到当前星级对应的那一颗时，星的上方出现提示 T100。依据 R2 |
| R2-05 | 点第 N 颗：星级变成 N（比当前低就降到 N）；点当前星级对应的那一颗：清除星级，提示 T01。每颗热区 19 × 24，相邻不留缝。鼠标点星不闪现胶囊、不自动下一张。依据 R2 |
| R2-06 | 窗口变窄时信息行让位：① 先隐藏尺寸文字 ② 再隐藏右边的大小 · 格式 ③ 最后文件名中间截断；星永远在、永远居中，文字和星之间至少留 14。依据 R2 |
| R2-07 | 当前位置不可写或当前文件不能评星（R1-09、R1-10）：整行 40% 不透明，点击不改星级，显示 T02 或 T03。依据 R2 |
| R2-08 | 缩略图栏隐藏时没有信息行，只能用键盘评星；全屏时鼠标移到底部、缩略图栏滑出，信息行里才有星。鼠标移动时照片上不出现任何和评星有关的东西。依据 R2、R3 |
| R2-09 | 视频文件：信息行中间不放星（左右两段照常），缩略图没有星级角标，信息面板没有评星组，序号不带「· ★N」，文件 › 评星 子菜单置灰。依据 R1、R2（视频不评星） |
| R2-10 | 读屏软件把信息行的星读作「评星」，每颗读作「N 星」，当前值读作 T05 / T06。依据 R2、R3 |
| R2-11 | 信息面板评星行里的五颗星（16pt）可以点，规则同 R2-05、R2-07。依据 R2、R3 |
| R3a-01 | 按 0–5（包括按下和当前相同的数字）时，画面底部居中的五星胶囊闪现约 1 秒：0.15 秒弹出，第 N 颗放大 130% 并发光，0.6 秒回落后淡出；胶囊不能点。用方向键切换、鼠标移动都不出现。依据 R3a |
| R3a-02 | 胶囊底边离窗口底边：缩略图栏显示 140；栏隐藏 32；全屏 140。水平在窗口正中，不随照片走。（视频不评星，原来视频的 182 / 70 取消）依据 R3a |
| R3a-03 | 设置 › 浏览「评星时在画面上闪现星级」T101（说明 T102），默认开；关掉后按键评星时画面上什么都不出现，反馈只在信息行、角标和序号里。依据 R3a |
| R3a-04 | 鼠标停在视频控制条上时不闪现（不挡进度条的时间气泡）。打星后自动下一张时，闪现开着就在新照片上闪现一次（显示新照片自己的星级）。依据 R3a、R8 |

## 4. 星级存在哪里、怎么写（PRD 4.3）

| 编号 | 规则 |
| --- | --- |
| S-01 | 写入位置按文件类型：RAW（CR2、CR3、NEF、ARW、RAF、RW2、ORF、DNG）→ .xmp 小文件；JPEG、PNG、HEIC / HEIF、TIFF → 内嵌（默认）；GIF、WebP、SVG、BMP → .xmp 小文件。视频（MP4、MOV、M4V）v0.3 不能评星：旁边别的软件写的 .xmp 不读、不改、删除视频时不跟着进废纸篓。依据 4.3 |
| S-02 | 设置 › 浏览 ›「星级保存到哪里」选「一律使用旁边的 .xmp 小文件」时，JPEG、PNG、HEIC / HEIF、TIFF 也改用 .xmp 小文件，一览不再改动这些图片本身。RAW 和 S-01 里本来就用小文件的类型不受这个选项影响。依据 4.3 |
| S-03 | 切换「星级保存到哪里」不搬动已有的星级：已经写在文件里或小文件里的星级都还在，读取按 R4-02 的先后顺序。待定 PD-05。依据 4.3 |
| S-04 | .xmp 小文件的名字：RAW 用「同名换扩展名」（`DSC_0812.ARW` → `DSC_0812.xmp`，和 Lightroom 一致，扩展名小写）。其他图片也优先用同名 `.xmp`；但如果文件夹里有另一个一览支持的文件和它同名（例如「一律小文件」时 RAW + JPEG 同名，或实况照片 `IMG_1.HEIC` + `IMG_1.MOV`），图片改用「完整文件名 + .xmp」（`IMG_1.HEIC.xmp`），不去碰可能属于视频或 RAW 的 `IMG_1.xmp`。视频自己不再有小文件。依据 4.3、PD-04 |
| S-05 | 写入在后台进行，不阻塞界面；切图、继续打星都不用等。依据 4.3、流畅度验收 |
| S-06 | 内嵌写入只改 XMP 信息块里的星级：JPEG 和 PNG 除 XMP 块以外的每个字节都不变（画面数据、EXIF、GPS、色彩描述文件、厂商信息）；HEIC 和 TIFF 的画面数据逐字节不变、解码出的像素不变。依据 4.3、验收「画面数据完全一致」 |
| S-07 | 内嵌写入先在同一文件夹里写一个隐藏的临时文件（名字以 `.yilan-` 开头），检查合格后再一次替换原文件；中途断电、磁盘满、程序退出时原文件保持原样，最多留下一个隐藏临时文件。依据 4.3 |
| S-08 | 一览打开文件夹时，删除这个文件夹里由一览留下、超过 10 分钟的 `.yilan-*` 临时文件；别的文件一概不碰。依据 4.3 |
| S-09 | 写入后文件的修改时间和写入前完全一样（存储卡的 FAT / exFAT 按它们自身的时间精度）；创建时间、权限、访达标签也保持不变。依据 4.3、验收 |
| S-10 | 已有 .xmp 小文件时只改星级一项：调色参数、关键词、标题、其他软件自己的信息都原样保留（文件里的排版、空白可能变化，内容不变）。依据 4.3、验收 |
| S-11 | 新建 .xmp 小文件时，文件里只有星级一项，并带上「由一览创建」的标记和 `photoshop:SidecarForExtension="<大写扩展名>"`（例如 ARW、DNG，Adobe 的写法，不带空格）；不往别的软件建的小文件里加这一项。依据 4.3、调研报告 A |
| S-11b | 写星级时，文件里已经有的其他星级字段改成相同的值，避免不同软件显示不同：XMP 里的 `MicrosoftPhoto:Rating`（百分制 1/25/50/75/99，清除时 0）；JPEG、PNG、TIFF、HEIC 里 Exif 的 Rating（0x4746）和 RatingPercent（0x4749）。只改已有的，不新增；Exif 的两个值只在能原地覆盖（同样字节数、原字节序）时改，不能时整次写入改用小文件。依据 4.3、调研报告 B |
| S-12 | 清除星级时：小文件是一览创建的、清除后里面不再有任何其他信息 → 直接删除这个小文件（不进废纸篓）；否则只删掉星级一项，文件保留。例外：RAW 本身带有机内星级（相机里打的星）时，小文件保留并记为 0，保证清除后显示未评星而不是又露出机内星级。依据 4.3 |
| S-13 | 内嵌文件清除星级：从文件信息里去掉星级；做不到去掉的格式（HEIC、TIFF）写成 0。0 在 Lightroom 等软件里也是「未评星」。依据 4.3 |
| S-14 | 写不进去（只读磁盘、写保护存储卡、没有权限）：显示 T02，4 秒淡出；界面上的星恢复成写之前的值；这次操作不进撤销记录。同一原因 10 秒内不重复提示。依据 4.3、验收 |
| S-15 | 磁盘已满：显示 T10，其他同 S-14。其他写入失败（例如文件被其他程序锁住）：显示 T11（带系统给出的原因），其他同 S-14。待定 PD-08。依据 4.3 |
| S-16 | 打开文件夹时就判断位置是否可写；不可写时五星胶囊和信息面板的星显示为 40% 不透明（R2-09），不用等到写失败。依据 4.3、设计稿「文件不可写」 |
| S-17 | 第一次为 RAW 创建 .xmp 小文件后，顶部出现提示卡片 T12 / T13 / 按钮 T14；只出现一次（之后任何文件夹都不再出现），点「知道了」或 × 关闭；不压暗、不阻止操作。依据 4.3、设计稿 1.4 |
| S-18 | 写入前重新读取文件当时的内容再改星级（不是用一览打开时读到的旧内容），所以别的软件在这期间写进去的其他信息也会保留。依据 4.3、R4 |
| S-19 | 写入排队时文件被删除、移走或改名：放弃这次写入，不提示（文件夹同步会按原规则处理文件变化）。依据 4.3 |
| S-20 | 退出一览时还有没写完的星级：最多等 3 秒写完再退出；超过 3 秒仍未完成的放弃（原文件不受影响，见 S-07）。依据 4.3 |
| S-21 | 内嵌写入后的自检不合格（读回的星级不对、图片尺寸变了、原有的 XMP 信息少了）：不替换原文件，改为写到 .xmp 小文件（按 S-04 命名），不提示用户，写日志。依据 4.3「做不到的格式改用旁边的小文件」 |
| S-22 | JPEG 的 XMP 信息块超过格式上限（64 KB）、PNG 的 XMP 是压缩存储的，同 S-21 改用小文件。依据 4.3 |
| S-23 | 删除文件到废纸篓时，它的 .xmp 小文件一起进废纸篓；撤销删除时一起放回原处。两个 RAW 共用同一个小文件（如 `A.CR3` 和 `A.DNG`）时，删除其中一个不动小文件。依据 4.3、验收 |
| S-24 | 只读取星级不会写任何文件（打开文件夹、浏览、筛选都不改动磁盘）。依据 4.3、目标「不损坏原图」 |

## 5. 读取已有星级（R4）

| 编号 | 规则 |
| --- | --- |
| R4-01 | 星级来源：文件内嵌的 XMP 星级（包括相机机内评星，只要系统能读出）、旁边的 .xmp 小文件（Lightroom、Capture One、一览等写的）。依据 R4 |
| R4-02 | 两处都有时：RAW 以小文件为准，DNG 例外：内嵌和小文件都读，取修改时间较新的那个，一样新时以小文件为准；其他图片也是小文件优先（小文件只会在「一律使用小文件」、写入回退、或其他软件明确生成时存在），没有小文件才看内嵌。依据 R4、4.3、调研报告 A |
