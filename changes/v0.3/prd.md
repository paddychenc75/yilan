# 一览 v0.3 需求文档（PRD）：评星与筛选

状态：已确认（2026-11-17）。上一个公开版本是 v0.2.1。

## 一、背景与用户反馈

v0.2 发布后收到两条评论，都肯定了流畅度和颜值，提出两个缺口：评星筛选和基础修图。

| 评论原文 | 用户想要的 | 归属版本 |
| --- | --- | --- |
| 「一般需要做大量 raw 预览的人，可能都需要做快速分拣、筛选，所以如果能有评星、选星功能就更棒了」 | 看 RAW（相机原始格式照片）时边看边打星，再按星级筛出好片 | v0.3 |
| 「功能简单了点，没有修图功能，建议加点基本的修图功能，例如放大缩小，裁切」 | 裁切；以及更容易找到的放大缩小 | 缩放入口在 v0.3，裁切在 v0.4 |

「放大缩小」现在已经有（双击、+ / − 键、Ctrl + 滚轮），但界面上只在放大后才出现一个不可点击的比例胶囊，没放大过的用户看不到任何入口。

## 二、目标与不做的事

**目标**

- 拍完一批 RAW，用户只用键盘就能完成「浏览、打星、筛出好片」，不必先打开 Lightroom（Adobe 的专业修图软件）。
- 在一览里打的星，Lightroom、Capture One 等主流软件也能看到。
- 新用户在界面上一眼能找到放大缩小。
- 任何情况下都不损坏、不意外覆盖用户的原图。
- 流畅度不比 v0.2.1 差。

**不做的事**

- 裁切、保存旋转、调整尺寸导出（v0.4）。
- 调色、滤镜等画质调整，RAW 显影。
- 跨文件夹的图库、相册、云同步。
- 颜色标签、旗标（留用 / 排除）、关键词。
- RAW 和 JPEG 同名文件配对处理。
- 浅色界面。

## 三、使用场景

**场景 A：拍完选片（摄影用户）**

小周周末拍了 800 张 RAW，想挑出 30 张来修。

1. 用一览打开存储卡文件夹里的任意一张。
2. 按方向键一张张看，觉得不错就按 1 到 5 打星，手不离键盘。
3. 拿不准清晰度时，按 Z 放大到实际大小看细节，再按 Z 回来。
4. 看完一遍，把筛选切到「3 星及以上」，只剩 60 张。
5. 在这 60 张里再看一遍，把最好的升到 5 星。
6. 把 5 星的照片一次性复制到「待修」文件夹，或者直接打开 Lightroom，星级已经在那里了。

**场景 B：找不到放大缩小（新用户）**

新用户打开一张大图，想看细节，但不知道快捷键，也没想到双击。他应该在顶部操作区域一眼看到放大、缩小按钮和当前比例。

## 四、功能需求

### 4.1 功能清单

| 编号 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| R1 | 打星 | 按 1 到 5 给当前文件打对应星级，按 0 清除。再按一次相同数字不变 | 必须做 |
| R2 | 鼠标打星 | 舞台底部居中（缩略图栏上方）有一个五星胶囊，点第几颗就是几星，点当前星级的那一颗清除。胶囊不常驻：鼠标移动时和箭头等控件一起出现并淡出；按 0 到 5 时单独闪现约 1 秒；用方向键切图时不出现，不遮挡照片 | 必须做 |
| R3 | 星级显示 | 底部缩略图左上角显示「★ 数字」角标（只在有星时显示）；信息面板有星级一行；缩略图栏隐藏或全屏时，右上角计数补上星级，如「9 / 20 · ★4」 | 必须做 |
| R4 | 读取已有星级 | 打开文件夹时读出相机机内打的星、Lightroom 等软件打的星，直接显示 | 必须做 |
| R5 | 按星级筛选 | 在现有「全部 / 图片 / 视频」旁加星级筛选：不限、星级不低于 1 到 5、未评星。可与类型筛选叠加 | 必须做 |
| R6 | 筛选计数 | 筛选菜单每一项后面显示符合的文件数；筛选后右上角计数显示在结果中的位置和结果总数（如「3 / 60」） | 必须做 |
| R7 | 撤销 | ⌘Z 撤销上一次打星，与现有的「撤销删除」共用一条撤销记录 | 必须做 |
| E1 | 顶部缩放控件 | 取消左下角的比例胶囊，在顶部操作区域新增常驻的缩放控件：「−」缩小、当前比例（如 100%）、「+」放大；适应窗口时也显示。点比例数字可选「适应窗口 / 实际大小 / 200%」。随顶部栏一起自动隐藏；窗口变窄时按设计稿的规则收缩，不与其他控件重叠 | 必须做 |
| B1 | 问题修复 | 双击窗口顶部标题栏区域，现在会把图片放大到 200%，应改为按系统设置放大或最小化窗口。修复代码在本地分支 `fix/titlebar-double-click` | 必须做 |
| R8 | 打星后自动下一张 | 设置里的开关，默认关 | 尽量做 |
| R9 | 导出筛选结果 | 把当前筛选出的全部文件复制或移动到用户指定的文件夹，附带的星级文件一起带走 | 尽量做 |

### 4.2 快捷键变化

数字键 1 到 5 打星、0 清除，是 Lightroom 等选片软件的共同习惯。它占用了一览现有的两个缩放快捷键，调整如下：

| 操作 | v0.2 | v0.3 |
| --- | --- | --- |
| 打 1 到 5 星 | 无 | 1 到 5 |
| 清除星级 | 无 | 0 |
| 实际大小 | 1 | ⌘0（与系统「预览」一致） |
| 适应窗口 | 0 | ⌘9（与系统「预览」一致） |
| 在适应窗口和实际大小之间切换 | 双击照片 | 双击照片，或按 Z |
| 切换全部 / 图片 / 视频 | ⌘1 / ⌘2 / ⌘3 | 不变 |

更新后首次启动，用一条可关闭的提示说明这次变化。

### 4.3 星级存在哪里

星级用 XMP（Adobe 制定、各家修图软件通用的照片附加信息格式）保存，按文件类型分两种写法：

| 文件类型 | 写法 | 原因 |
| --- | --- | --- |
| RAW | 在照片旁边生成一个同名的 .xmp 小文件，不动 RAW 本身 | RAW 是底片，绝不改写 |
| JPEG、HEIF、TIFF、PNG | 把星级写进文件自带的信息区，画面数据不重新压缩 | 其他软件只从这类文件内部读星级 |
| 视频、GIF、WebP、SVG | 同名 .xmp 小文件 | 这些格式写入内部不可靠 |

设置里提供一个选项，可改成「一律使用旁边的 .xmp 小文件」。

写入规则：

- 写入在后台进行，界面上的星立即点亮，不等磁盘。
- 写入文件内部时先写临时文件再替换，中途断电也不会弄坏原图；保留文件原来的修改时间。
- 已有 .xmp 小文件时只改星级一项，其他软件写的调色参数原样保留。
- 清除星级时，如果 .xmp 小文件是一览创建的且里面只有星级，就删掉它。
- 写不进去时（存储卡写保护、只读磁盘、没有权限），提示「无法保存星级：此位置不可写」，界面上的星恢复原状。
- 第一次在 RAW 旁边生成 .xmp 小文件时，用一句话提示说明它的用途。
- 删除文件到废纸篓时，它的 .xmp 小文件一起进废纸篓；撤销删除时一起回来。

### 4.4 筛选的细节

- 筛选状态下给照片改星，导致它不再符合条件时，它留在列表里直到用户切换到别的照片。
- 筛选结果为空时显示「没有符合条件的文件」和一个「清除筛选」按钮。
- 星级筛选只在当前窗口生效，换文件夹后回到「不限」。
- 其他软件在一览打开期间改了星级，一览跟随更新（沿用现有的文件夹同步）。

## 五、验收标准

测试素材只用公开授权的图片和视频，不用个人照片。

**评星与筛选**

- [ ] 按 1 到 5 后，界面上的星在 0.1 秒内点亮；按 0 清除。
- [ ] 给 RAW 打星后，旁边生成同名 .xmp 小文件，RAW 文件本身的内容一个字节都没变。
- [ ] 给 JPEG 打星后，画面数据和打星前完全一致，文件修改时间不变。
- [ ] 在一览里打的星，用 Lightroom Classic 导入后能看到相同星级；反过来，Lightroom 打的星一览也能显示。
- [ ] 已有 .xmp 小文件里的调色参数，在一览改星后原样保留。
- [ ] 在写保护的存储卡上打星，出现「无法保存星级」提示，星恢复原状，程序不崩溃。
- [ ] 选择「星级不低于 3」后，底部缩略图只剩符合条件的文件，计数正确，方向键只在结果内切换。
- [ ] ⌘Z 能撤销上一次打星，文件里的星级同步恢复。
- [ ] 删除带星的 RAW，.xmp 小文件一起进废纸篓；撤销后两者都回来。
- [ ] 中文和英文界面都有完整文案。

**缩放与快捷键**

- [ ] 顶部操作区域能看到「−」、当前比例、「+」，适应窗口时也显示；点比例能选适应窗口、实际大小、200%。
- [ ] 窗口从宽拖到最窄的过程中，顶部各控件不重叠、不被裁掉。
- [ ] ⌘0 是实际大小、⌘9 是适应窗口、Z 在两者之间切换，⌘1 / 2 / 3 仍然切换类型，菜单和设置里的文字同步更新。
- [ ] 在顶部标题栏区域双击，窗口按系统设置放大或最小化，图片缩放比例不变；在图片上双击仍然放大图片。

**流畅度**

- [ ] 打开 2000 张 RAW 的文件夹，首张图出现的时间与 v0.2.1 相比没有可察觉的变慢。星级在后台陆续读出。
- [ ] 按住方向键连续切图、连续打星时不卡顿。
- [ ] 2000 张的文件夹切换星级筛选，结果在 0.3 秒内出现。

## 六、已确认的决定

| 决定 | 结论 |
| --- | --- |
| 评星和裁切是否拆版本 | 拆。v0.3 评星，v0.4 裁切 |
| 数字键是否改给评星 | 改。缩放用 Z、⌘0、⌘9，类型切换不动 |
| JPEG 等是否把星级写进文件内部 | 允许，只写附加信息；设置里可改成一律用小文件 |
| 五星控件位置 | 舞台底部居中的玻璃胶囊，不常驻 |
| 缩略图星标 | 左上角「★ 数字」角标 |
| 缩放控件位置 | 顶部操作区域 |

## 七、风险

- **写用户文件的风险**。这是一览第一次修改用户的文件（此前只有删除到废纸篓）。写入必须先写临时文件再替换，并用自动测试覆盖断电、磁盘满、只读等情况。
- **兼容性没有实测**。「Lightroom 读 RAW 旁边的小文件、读 JPEG 内部信息」是行业惯例，还没有用真实软件验证。开发前要先用 Lightroom Classic 和 Capture One 各测一次。
- **HEIF 等格式能否只改附加信息而不重新压缩画面**，需要开发时验证。做不到的格式改用旁边的小文件。
- **老用户按 0 或 1 想缩放，结果改了星级**。靠首次启动提示和 ⌘Z 撤销兜底。
- **将来上架 Mac App Store**。上架要求的沙盒（系统对应用读写文件的限制）会影响在照片旁边生成小文件。目前不上架，暂不处理，但实现时要把读写集中在一处，方便日后调整。
